## Como usar este arquivo

Este perfil é **seu espelho** — edite à mão quando algo mudar. Skills de IA leem
este arquivo para entender contexto antes de escrever pesquisa ou contexto de
projeto para você.

O que é útil ter aqui:

- Quem você é profissionalmente (elevator pitch em 2-3 linhas)
- Suas áreas de expertise
- Seus projetos atuais (com 1 linha cada)
- Suas preferências de comunicação (tom, idioma, nível de formalidade)

O que **não** colocar aqui:

- Senhas, informações sensíveis (não é um cofre)
- Journaling profundo (vai em `Journaling/`)
- Registros factuais diários (vai em `Diario/`)
